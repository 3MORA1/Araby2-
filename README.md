## ⚙️ 3. الدوال والميزات المتاحة

### أ) دوال الطباعة والإدخال
* **`اطبع_سطر(المحتوى)`**: طباعة نص أو متغير مع النزول لسطر جديد.
* **`اطبع(المحتوى)`**: طباعة نص أو متغير في نفس السطر.
* **`سطر_جديد()`**: طباعة سطر فارغ.
* **`اقرأ_نصاً("الرسالة")`**: استقبال مدخل نصي من المستخدم عبر الكونسول.
* **`اقرأ_رقماً("الرسالة")`**: استقبال رقم من المستخدم.

### ب) الدوال والثوابت الرياضية
* **`جذر(س)`**: حساب الجذر التربيعي للرقم.
* **`قوة(س، ص)`**: حساب الأس والرفع لقوة (س^ص).
* **`مطلق(س)`**: القيمة المطلقة بدون إشارة.
* **`جمع(س، ص)`** / **`طرح(س، ص)`** / **`ضرب(س، ص)`** / **`قسمة(س، ص)`**: العمليات الحسابية الأساسية.
* **`باي`**: الثابت الرياضي π (3.14159...).
* **`ثابت_هاء`**: الثابت الرياضي e (2.71828...).



## 💻 4. أمثلة وشرح التجهيز والتنفيذ

### الطريقة الأولى: التنفيذ الديناميكي للكود العربي (`نفذ_الكود_العربي`)

تسمح لك بكتابة الكود كاملاً بلغة عربية نصية داخل النص المتعدد الأسطر (Text Block) وتنفيذه مباشرة:

```java
package mycode;

import static mycode.Arabu.*;

public class Main {
    public static void main(String[] args) {

        String كود_عربي = """
            برنامج
                عرف اسم = "عمر";
                عرف س = 16.0;
                اطبع_سطر("أهلا بك يا " + اسم);
                اطبع_سطر("جذر الرقم هو: " + جذر(س));
            انهاء
            """;

        نفذ_الكود_العربي(كود_عربي);
    }
}

المخرجات المتوقعة في الـ Console:
أهلا بك يا عمر
جذر الرقم هو: 4.0



الطريقة الثانية: الاستدعاء المباشر للدوال داخل كود Java
يمكنك استخدام الدوال العربية كدوال استدعاء مباشرة كالتالي:

package mycode;

import static mycode.Arabu.*;

public class Main {
    public static void main(String[] args) {

        String الاسم = "علي";
        double نق = 5.0;

        اطبع_سطر("مرحباً بك يا " + الاسم);
        
        // حساب مساحة الدائرة = باي * نق^2
        double المساحة = ضرب(باي, قوة(نق, 2));
        اطبع_سطر("مساحة الدائرة تساوي: " + المساحة);
    }
}
